## 1. ขอบเขตการทำงาน (Feature Scope)

1. **แสดงรายการและตำแหน่งคำขอขายของเก่าบนแผนที่ (`REQ-FN-002`, `REQ-QA-002`, `REQ-SEC-002`, `D-00-02`):**
   - อ่านพิกัดปัจจุบันของซาเล้งจาก `GPS` และค้นหาเฉพาะคำขอขายสถานะ `"รอผู้รับงาน"` (`Pending / S2`) ที่อยู่ในรัศมีโครงข่ายถนนไม่เกิน `5.0 กิโลเมตร`
   - คำนวณระยะทางตามเส้นทางถนนจริง (Road Network Distance) แสดงผลภายใน `<= 3.0 วินาที (p95)` (`REQ-QA-002`)
   - **การคุ้มครองข้อมูลส่วนบุคคล (`REQ-SEC-002`, `D-00-02`, `CC-06`, `Q-01`):** ก่อนที่ซาเล้งจะกดรับงานสำเร็จ API และหน้าจอจะตัดบ้านเลขที่และพิกัดจริงทิ้ง โดยส่งเฉพาะ **พิกัดเบี่ยงเบนสุ่ม (Fuzzed Coordinates ±300–500 ม.)** หรือจุดกึ่งกลางตำบล/แขวง พร้อมระบุชื่อเฉพาะระดับ **`ตำบล/แขวง และอำเภอ/เขต`** (เช่น "แขวงลาดยาว เขตจตุจักร")
   - **กรณีไม่พบงานในรัศมี 5.0 กม. (`Extension A1`, `AC-B02-02`, `Q-06`):** แสดงข้อความ `"ยังไม่มีงานในเส้นทาง"` พร้อมปุ่มกดขยายรัศมีเป็น `10.0 กม.`

2. **ระบบสลับมุมมอง รายการงาน ⇄ แผนที่ บนจอมือถือ (`Mobile-First View Switcher` — `CC-01`, `REQ-UX-001`, `Q-04`):**
   - มีปุ่ม Segmented Control สลับระหว่าง:
     - **`[ 📋 รายการงาน ]` (List View):** การ์ดรายการคำขอขาย แสดงชื่อแขวง/เขต, ระยะทาง กม., มูลค่าประเมิน, ป้ายหมวดหมู่วัสดุ, น้ำหนักประเมิน และปุ่มกดดูรายละเอียด (ความสูง `>= 48px`)
     - **`[ 🗺️ แผนที่งาน ]` (Map View):** แสดงแผนที่แบบเต็มจอ พร้อมหมุดตำแหน่งจำลองของผู้ขาย หมุดตำแหน่งปัจจุบันของซาเล้ง และพรีวิวการ์ดย่อเมื่อแตะหมุด

3. **ตัวกรองและการจัดเรียงคำขอขาย (`Multi-Criteria Job Filtering & Sorting` — `REQ-FN-002`, `Q-03`):**
   - **กรองตามหมวดหมู่วัสดุ:** Multi-select 5 หมวด (`กระดาษ`, `พลาสติก`, `แก้ว`, `โลหะ`, `ของชิ้นใหญ่/เครื่องใช้ไฟฟ้า`)
   - **กรองตามช่วงน้ำหนักประเมิน:** ทั้งหมด, ขนาดเล็ก (`< 50 กก.`), ขนาดกลาง (`50–100 กก.`), ขนาดใหญ่ (`> 100 กก.`)
   - **การจัดเรียงลำดับ:** เรียงตามระยะทางใกล้สุด (Default) หรือ เรียงตามมูลค่าประเมินสูงสุด

4. **การแจ้งเตือนงานใหม่ในพื้นที่ (`In-App Live Alert & Notification Badge` — `Q-02`):**
   - กลไก In-App Auto-Refresh / Polling ทุก 30–60 วินาที ตรวจจับคำขอขายใหม่ในรัศมี 5.0 กม.
   - แสดง Toast Banner แจ้งเตือนสีเขียว `"มีงานใหม่ใกล้คุณ X.X กม."` พร้อมเสียงแจ้งเตือนสั้น ๆ (Audio Ping) และปุ่มกดดูงานใหม่ทันที

5. **การทำงานร่วมกับกฎเหล็ก Unverified Collector Gate (`D-00-01`, `Q-05`):**
   - ซาเล้งที่ยังไม่ผ่านการอนุมัติ KYC (`verified = false`) สามารถเปิดดูรายการงานและแผนที่ได้ แต่ปุ่มกดรับงานจะล็อกแสดงรูปกุญแจพร้อมแจ้งเตือน
   - หากพยายามกดรับงาน จะแสดง Informative Gate Modal พร้อมปุ่มนำทางไปยังหน้าส่งเอกสารยืนยันตัวตนใน Buyer 01 ทันที

6. **ระบบสำรองการคำนวณระยะทางเมื่อระบบแผนที่ภายนอกขัดข้อง (`Dual-Engine Routing Fallback` — `CC-03`, `REQ-OP-002`):**
   - หาก OSRM / Maps API ภายนอกล้มเหลวหรือไม่ตอบสนองภายใน 1.5 วินาที ระบบจะสลับไปใช้สูตร **`Haversine * 1.35`** อัตโนมัติทันที
   - การตอบสนองต้องเสร็จสิ้นภายใน `<= 2.0 วินาที` พร้อมระบุ Flag `is_fallback: true`

## 4. ข้อสรุปประเด็นคำถามเปิด (`Open Questions Resolved` — `Q-01` ถึง `Q-06`)

- **`Q-01` (การซ่อนพิกัดหมุดบนแผนที่ก่อนรับงาน):** ใช้เทคนิค **Coordinate Fuzzing (สุ่มเบี่ยงเบนพิกัด ±300–500 ม.)** ร่วมกับจุดศูนย์กลางตำบล/แขวง เพื่อแสดงหมุดโดยประมาณบนแผนที่ โดยคำนวณระยะทางถนนจริงอย่างแม่นยำที่หลังบ้าน เพื่อปฏิบัติตามกฎ PDPA และ `D-00-02` 100%
- **`Q-02` (ขอบเขตการแจ้งเตือนงานใหม่):** ใช้กลไก **In-App Polling / Auto-refresh ทุก 30–60 วินาที** พร้อม Toast Banner สีเขียวด้านบน, เสียง Audio Ping และ Notification Badge ในแอปรอบ R1
- **`Q-03` (ตัวเลือกการกรองงาน):** รองรับ 3 มิติ ได้แก่ หมวดหมู่วัสดุ 5 กลุ่ม, ช่วงน้ำหนักประเมิน 4 ช่วง, และจัดเรียงตามระยะทางใกล้สุด (Default) หรือมูลค่าประเมินสูงสุด
- **`Q-04` (โครงสร้างหน้าจอมือถือ):** ใช้ **Segmented Control Tab Switcher** ด้านบน สลับระหว่าง `List View` และ `Map View` ขนาดปุ่มกด `>= 48px` เพื่อความลื่นไหลบนมือถือราคาประหยัด (`RAM >= 2 GB` ตาม `CC-01`)
- **`Q-05` (Unverified Collector Access):** ซาเล้งที่ยังไม่ผ่าน KYC สามารถเปิดดูรายการงานและแผนที่ได้ แต่ปุ่มกดรับงานจะล็อกด้วยแม่กุญแจ และมี Modal แจ้งเตือนสิทธิ์ตามกฎ `D-00-01`
- **`Q-06` (การขยายระยะทาง 10 กม.):** ค่าเริ่มต้นคือ 5.0 กม. เสมอเมื่อเปิดหน้าจอใหม่ หากกดยอมรับขยายเป็น 10.0 กม. ระบบจะคงค่านี้ไว้ตลอดเซสชันปัจจุบันในแอป
