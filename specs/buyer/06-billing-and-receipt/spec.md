  - In Scope: **`SC-03: การบันทึกสรุปน้ำหนัก รายการขยะ และยอดเงินหลังการซื้อขายเสร็จสิ้น`**
  - State Machine กลาง: **`MD-STM-04` สถานะ `S4 (Weighing)` -> `S5 (Re-Quote / Weight Confirmation)` -> `S6 (Settled / Pending Payment)` -> `S7 (Completed)` และ `S8 (Disputed)`** ([`specs/002-route/models.md`](../../002-route/models.md))
  - สเปกคู่ขนานฝั่งผู้ขาย: [`specs/seller/06-payment-and-verification/spec.md`](../../seller/06-payment-and-verification/spec.md)
  - ความต้องการที่เกี่ยวข้อง:
    - **`REQ-FN-002`**: บันทึกน้ำหนักชั่งจริงหน้างานและแนบภาพถ่ายหน้าตาชั่งดิจิทัล
    - **`REQ-FN-004`**: ผู้ขายตรวจสอบและยืนยันน้ำหนักชั่งจริงก่อนสรุปยอดเงิน (Seller Confirmation Gate 100%)
    - **`REQ-FN-005`**: สร้างใบเสร็จดิจิทัล (`DigitalReceipt`) รหัสอ้างอิงไม่ซ้ำ น้ำหนักชั่งจริง ราคาล็อกต่อหน่วย และยอดชำระสุทธิ
    - **`REQ-BR-002`**: ใช้ราคาต่อหน่วยที่ล็อกไว้ตอนนัดหมาย (`locked_unit_price`) มาคำนวณยอดชำระสุทธิ (`actual_weight * locked_unit_price`)
    - **`REQ-OP-001` / `CT-02` (หน้า 44)**: โหมดกึ่งออฟไลน์ในจุดอับสัญญาณขณะชั่งน้ำหนักและบันทึกราคา พร้อม Offline Queue ซิงก์เมื่อมีสัญญาณ
    - **`REQ-SEC-001`**: บันทึกประวัติการเปลี่ยนสถานะใบงานลงในตาราง Audit Log
    - **`REQ-SEC-002` / `CC-06`**: ปกปิดเบอร์โทรศัพท์บนใบเสร็จดิจิทัลเป็น `08X-XXX-XXXX`
    - **`REQ-UX-001` / `CC-01`**: ทัชทาร์เก็ตปุ่มกดขนาดใหญ่ `>= 48px` รองรับสมาร์ตโฟนราคาประหยัด

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **บันทึกค่าน้ำหนักชั่งจริงและแนบภาพถ่ายหน้าตาชั่ง (`Actual Weight & Scale Photo` — `UC-05`, `REQ-FN-002`, `D-B06-02`):**
   - เมื่อซาเล้งเดินทางถึงหน้างาน (`S3 -> S4: ถึงจุดนัดหมายและชั่งของ`) ซาเล้งทำการชั่งน้ำหนักของเก่าจริงหน้างาน
   - ซาเล้งกรอกตัวเลขน้ำหนักจริง (`actual_weight`) แยกตามชนิดสิ่งของที่นัดรับ (กก. หรือ จำนวนกระสอบ)
   - บังคับถ่ายภาพหน้าตาชั่งดิจิทัล (`scale_photo_url`) อย่างน้อย 1 ภาพ เพื่อส่งให้ผู้ขายตรวจสอบความโปร่งใสผ่านหน้าจอ
2. **คำนวณยอดเงินตามราคาที่ล็อกไว้ (`Locked Unit Price Calculation` — `REQ-BR-002`, `D-B06-03`):**
   - ระบบคำนวณยอดเงินแต่ละรายการและยอดสุทธิรวมโดยใช้ **ราคาต่อหน่วยที่ล็อกไว้ตอนนัดหมาย (`locked_unit_price`)** คูณกับน้ำหนักชั่งจริง:
     $$\text{ยอดชำระสุทธิ} = \sum (\text{actual\_weight} \times \text{locked\_unit\_price})$$
   - ตรวจสอบส่วนต่างน้ำหนักเทียบกับที่ประเมินไว้เบื้องต้น (`±15%` ตาม `MD-STM-04`) และส่งตัวเลขไปยังหน้าจอผู้ขายเพื่อรอการยืนยัน
3. **ประตูการตรวจสอบความถูกต้องโดยผู้ขาย (`Seller Confirmation Gate 100%` — `REQ-FN-004`, `UC-06`, `D-B06-01`):**
   - ในสถานะ `S4/S5`: หน้าจอซาเล้งจะแสดงสถานะ *"รอผู้ขายตรวจสอบและยืนยันตัวเลขน้ำหนัก"*
   - **กฎเหล็ก (100% Gate):** ระบบจะบล็อกหน้าจอซาเล้งไม่ให้ข้ามไปขั้นตอนการชำระเงินหรือออกใบสรุปยอด จนกว่าผู้ขายจะกดยืนยันตัวเลขน้ำหนักบนหน้าจอของตนเองสำเร็จ จึงจะเปลี่ยนสถานะเป็น `S6: รอยืนยันชำระเงิน`
4. **กระบวนการชำระเงินหน้างาน (`Payment Method & Confirmation` — `UC-07`, `D-B06-04`):**
   - ในสถานะ `S6`: ซาเล้งเลือกช่องทางการจ่ายเงินค่าของเก่าให้แก่ผู้ขาย:
     - **`เงินสด (Cash)`:** ซาเล้งส่งมอบเงินสดให้ผู้ขายครบตามยอดสุทธิ
     - **`PromptPay QR Code`:** ซาเล้งใช้แอปพลิเคชันธนาคารของตนเองสแกน QR Code PromptPay ที่ผู้ขายแสดงบนหน้าจอ
   - เมื่อผู้ขายได้รับเงินครบถ้วน ผู้ขายจะเป็นผู้กดยืนยัน *"ได้รับเงินเรียบร้อยแล้ว"* บนหน้าจอของตนเอง คำขอจึงจะเปลี่ยนสถานะเป็น `S7: สำเร็จ / ปิดงาน (Completed)`
5. **ออกใบเสร็จสรุปรายการดิจิทัล (`Digital Summary Receipt` — `SC-03`, `REQ-FN-005`, `REQ-SEC-002`, `D-B06-06`):**
   - เมื่อสถานะเปลี่ยนเป็น `S7 (Completed)` ระบบออกใบเสร็จดิจิทัล (`DigitalReceipt`) โดยอัตโนมัติให้แก่ซาเล้งและผู้ขาย
   - แสดงรหัสใบเสร็จไม่ซ้ำ (`REC-YYYYMMDD-XXXX`), วันที่-เวลา, รายการสิ่งของ, น้ำหนักจริง, ราคาต่อหน่วยที่ล็อกไว้, ยอดเงินสุทธิรวม, ช่องทางชำระเงิน
   - ปกปิดข้อมูลส่วนบุคคลตาม PDPA โดย Mask เบอร์โทรศัพท์เป็น `08X-XXX-XXXX`
6. **การรองรับโหมดกึ่งออฟไลน์ในจุดอับสัญญาณ (`Offline Queue` — `CT-02` หน้า 44, `CC-05`, `REQ-OP-001`, `D-B06-05`):**
   - หากซาเล้งอยู่ในซอยอับสัญญาณขณะชั่งน้ำหนัก แอปสามารถบันทึกตัวเลขน้ำหนักและรูปภาพลงใน `localStorage` (`saleng_weighing_offline_queue`) พร้อม `idempotency_key`
   - เมื่อสัญญาณอินเทอร์เน็ตกลับมา ระบบจะซิงก์ข้อมูลขึ้นเซิร์ฟเวอร์อัตโนมัติทันที

## 2. ขอบเขตและสิ่งที่จงใจไม่ทำ (Scope & Non-goals)

> [!IMPORTANT]
> **สิ่งที่ไม่อยู่ในขอบเขตของฟีเจอร์นี้ (Non-goals — `D-B06-04`):**
> 1. **ไม่ทำระบบกระเป๋าเงินดิจิทัล (In-App Wallet) หรือ Payment Gateway ตัดบัตรเครดิตในแอป:** การชำระเงินใช้เงินสดหน้างาน หรือเปิดแอปธนาคารสแกน PromptPay ของผู้ขายโดยตรง
> 2. **ไม่ให้ซาเล้งกดยืนยันปิดงานฝ่ายเดียว:** การปิดงานเข้าสู่ `S7` ต้องได้รับการยืนยันการรับเงินจากผู้ขายเพื่อความปลอดภัยสูงสุดและป้องกันข้อพิพาท
> 3. **ไม่รวมการให้คะแนนและรีวิวหลังจบงาน (`UC-10`):** ตัดไปอยู่ใน Buyer Feature 07 (`specs/buyer/07-post-job/`) ตามผัง Use Case สากล

## 5. แบบจำลองข้อมูลและข้อกำหนด UI

### 5.1 โครงสร้างข้อมูลการบันทึกน้ำหนักจริงหน้างาน (`WeighingRecordRequest`)
```json
{
  "order_id": "order-s2-01",
  "collector_id": "saleng-01",
  "scale_photo_url": "https://storage.saleng.app/scales/scale-01.jpg",
  "items": [
    {
      "item_id": "item-01",
      "category_code": "MAT-CARDBOARD",
      "actual_quantity": 25.5
    }
  ]
}
```

### 5.2 โครงสร้างข้อมูลใบเสร็จดิจิทัล (`DigitalReceipt`)
```json
{
  "receipt_id": "REC-20261104-0001",
  "order_id": "order-s2-01",
  "issued_at": "2026-11-04T11:30:00Z",
  "seller_id": "seller-01",
  "seller_name": "คุณวิภาดา รัชดา",
  "seller_phone_masked": "081-XXX-5678",
  "collector_id": "saleng-01",
  "collector_name": "สมชาย ขยันเก็บ",
  "collector_phone_masked": "089-XXX-8888",
  "payment_method": "PROMPTPAY",
  "total_settled_amount": 89.25,
  "items": [
    {
      "category_name": "กระดาษลัง",
      "actual_quantity": 25.5,
      "unit": "กก.",
      "locked_unit_price": 3.5,
      "settled_item_price": 89.25
    }
  ]
}
```

### 5.3 ข้อกำหนดโครงหน้าจอ UI (`data-req="UC-07"`)
- **Weighing Input Screen (`S4`):** ช่องกรอกน้ำหนักจริงแยกแต่ละรายการ, ปุ่มถ่าย/อัปโหลดภาพตาชั่งดิจิทัล, ปุ่มกดยืนยันผลชั่ง (ความสูง `>= 48px` ตาม `REQ-UX-001`, `CC-01`)
- **Waiting Gate Screen (`S5`):** แสดงตัวเลขสรุปพร้อมแอนิเมชันรอผู้ขายกดยืนยันตัวเลขน้ำหนัก (บล็อกไม่ให้ไปยังขั้นตอนชำระเงิน)
- **Settlement & Payment Screen (`S6`):** แสดงยอดเงินสุทธิรวม, ปุ่มตัวเลือกช่องทางชำระเงิน `"เงินสด"` และ `"PromptPay QR Code"` ขนาดใหญ่ `>= 48px`
- **Receipt Screen (`S7`):** แสดงใบเสร็จดิจิทัลสรุปรายการครบถ้วน พร้อมปุ่มบันทึก/พิมพ์ใบเสร็จ (ทัชทาร์เก็ต `>= 48px`)
- **Offline Banner:** แสดงแบนเนอร์แจ้งเตือนสถานะเมื่อทำงานในโหมดกึ่งออฟไลน์
