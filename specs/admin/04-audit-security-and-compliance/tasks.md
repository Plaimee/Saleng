  - `UC-12: จัดการราคากลางวัสดุรีไซเคิล` ([`specs/admin/02-benchmark-price-and-grading/spec.md`](../02-benchmark-price-and-grading/spec.md)) — บันทึก Audit Log การปรับราคา
- **Business Rules & Technical Decisions ที่เกี่ยวข้อง:**
  - `D-A04-01`: การสืบค้น กรอง และส่งออก Audit Trail Log: กรองตาม `action`, `actor_id`, `actor_role`, ช่วงวันที่ `start_date` ถึง `end_date` พร้อม pagination และปุ่มส่งออกไฟล์ `CSV` และ `JSON`
  - `D-A04-02`: การบังคับใช้สิทธิ์ RBAC 4 บทบาทผ่าน Header `X-Admin-Role`: `ADMIN` (สิทธิ์เต็ม), `AUDITOR` (Read-only Audit Log และรายงานชุมชน), `DPO` (จัดการ PDPA Compliance & Purge), `SUPPORT` (ช่วยเหลือทั่วไป ห้ามดู Audit Log) ปฏิเสธ 403 Forbidden หากไม่มีสิทธิ์
  - `D-A04-03`: รายงานสถิติขยะชุมชน (Anonymized Community Report): สรุปสถิติระดับเขต/แขวง รายเดือน/ปี แสดงน้ำหนักรวม มูลค่ารวม รอบรับซื้อ โดยตัดข้อมูล PII ออก 100% ส่งออกเป็น `CSV` และ `JSON` สำหรับ กทม./เทศบาล
  - `D-A04-04`: นโยบาย Data Retention & Purge ตาม PDPA: พิกัด GPS ซาเล้งเก็บรักษาไว้ไม่เกิน **90 วัน** แล้ว Purge ทิ้ง ข้อมูลบ้านเลขที่ผู้ขายเปิดเผยเฉพาะช่วงเดินทาง และกลับมา Masked ถาวรหลังจบงานเกิน **24 ชั่วโมง** พร้อม API สำหรับ DPO สั่งล้างข้อมูลหมดอายุ
  - `D-A04-05`: กลไกยืนยันความไม่เปลี่ยนแปลงของ Audit Log (Immutable Audit Trail & Integrity Hash): ทุกระเบียนใน `audit_logs` คำนวณ `log_hash` ด้วย `SHA-256` บันทึกแบบ Append-only พร้อมมี API ให้ Auditor ตรวจสอบ Integrity
  - `D-A04-06` / `CC-01` / `CC-05`: หน้าจอแดชบอร์ดความปลอดภัยและตรวจสอบ: คอมโพเนนต์ SPA 3 แท็บ (Audit Trail Viewer, Anonymized Community Report, PDPA Compliance & Retention) กำกับ `data-req="UC-13"`, ทัชทาร์เก็ตปุ่มกด $\ge 48\text{px}$ ทุกปุ่ม, ทำงานในโหมด Online-only
