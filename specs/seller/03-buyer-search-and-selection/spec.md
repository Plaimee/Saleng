    - **`REQ-SEC-002`**: ซ่อนพิกัดละเอียดและบ้านเลขที่จริงของผู้ขายในระหว่างการค้นหา
    - **`CC-03`**: คำนวณระยะทางถนนจริง รัศมี `<= 5.0 กม.` พร้อม Haversine Fallback
    - **`EV-01`**, **`EV-02`**, **`EV-08`**, **`EV-09`**: หลักฐานการสำรวจความต้องการ ([`docs/srs/evidence.md`](../../../docs/srs/evidence.md))

## 1. ขอบเขตการทำงาน (Feature Scope)

1. **แสดงโปรไฟล์ซาเล้งและสถานะการยืนยันตัวตน (`Saleng Profile & KYC Verification Display` — `REQ-QA-001`, `AC-S03-01`):**
   - แสดงรายชื่อซาเล้ง/ผู้รับซื้อที่ลงทะเบียน เปิดสถานะรับงาน (`Online`) และผ่านการยืนยันตัวตนแล้ว 100% (`verified = true` ตามเกณฑ์ `D-00-01`)
   - แสดงข้อมูลโปรไฟล์สำคัญ: รูปถ่ายใบหน้า, ชื่อเรียก/ชื่อจริง, ป้ายกำกับ **`"ยืนยันตัวตนแล้ว 100%"`**, คะแนนรีวิวเฉลี่ย (1.0–5.0 ดาว), สถิติจำนวนงานที่รับซื้อสำเร็จ, และประเภทยานพาหนะ (ซาเล้งพ่วงข้าง / ซาเล้งสามล้อ / รถกระบะ)
2. **ตรึงซาเล้งที่เคยใช้บริการไว้บนสุด (`Top Pinning for Previous Collectors` — `REQ-UX-001`, `AC-S03-02`, `Q-02`):**
   - หากผู้ขายเคยมีประวัติการซื้อขายสำเร็จและบันทึกซาเล้งท่านนั้นไว้ในรายการโปรด (`Favorite Collector` จาก `UC-10 / S7`) ระบบต้องตรึง (Pin) รายชื่อซาเล้งกลุ่มนี้ไว้บนสุดของผลการค้นหาเสมอ พร้อมป้ายสัญลักษณ์ **`"ซาเล้งที่เคยใช้บริการ"`** เพื่อให้ผู้ขายกดนัดซ้ำได้อย่างสะดวกและรวดเร็ว
3. **ระบบตัวกรองหลายมิติและจับคู่ขนาดยานพาหนะ (`Multi-Criteria Filter & Bulky Vehicle Match` — `REQ-FN-001`, `CC-03`, `Card 03`, `AC-S03-03`, `Q-03`):**
   - คำนวณระยะทางจากตำแหน่งนัดหมายของผู้ขายไปยังพิกัดปัจจุบันของซาเล้ง (รัศมีค่าเริ่มต้น `<= 5 กม.`) ตามสูตร Haversine/Road API
   - รองรับตัวกรอง:
     1. ระยะทาง (ใกล้ที่สุด, `<= 1 กม.`, `<= 3 กม.`, `<= 5 กม.`)
     2. ประเภทยานพาหนะ (ซาเล้งสามล้อทั่วไป, รถกระบะสำหรับของชิ้นใหญ่)
     3. ชนิดของเก่าที่รับซื้อ (สอดคล้องกับวัสดุในตะกร้าของผู้ขาย)
     4. คะแนนรีวิว (เช่น 4.0 ดาวขึ้นไป)
   - **ระบบจับคู่ของชิ้นใหญ่อัตโนมัติ (`Bulky Items Auto-Filter`):** หากในตะกร้าคำขอ (`UC-02`) มีของชิ้นใหญ่เหมาจ่าย (ตู้เย็น เครื่องซักผ้า แอร์ โซฟา ตาม `Card 03`) ระบบจะแจ้งเตือนและคัดกรองแนะนำเฉพาะซาเล้งที่มี **รถกระบะ (`Pickup Truck`)** หรือซาเล้งพ่วงข้างขนาดใหญ่ เพื่อป้องกันปัญหาขนย้ายไม่ได้หน้างาน
4. **ช่องทางติดต่อด่วนและการคุ้มครองข้อมูลส่วนบุคคล (`Direct Call/Chat Hook & PDPA Protection` — `REQ-SEC-002`, `CC-06`, `AC-S03-04`, `Q-04`):**
   - แสดงปุ่ม **"โทรด่วน"** เปิดแอปโทรศัพท์ (`tel:`) ไปยังหมายเลขของซาเล้ง และปุ่ม **"ส่งข้อความ"** เพื่อเปิดห้องแชตในระบบ (`UC-08`)
   - **การคุ้มครองข้อมูลส่วนบุคคล (PDPA Protection):** ในระหว่างการค้นหาและสอบถามนี้ ระบบจะไม่เปิดเผยบ้านเลขที่จริงและพิกัดแผนที่แบบละเอียดของผู้ขายให้ซาเล้งเห็น (ซาเล้งจะเห็นเพียงตำบล/แขวง และระยะทางโดยประมาณ) จนกว่าซาเล้งจะกดยืนยันรับงานสำเร็จ
5. **การส่งคำขอนัดหมายเจาะจงรายบุคคล (`Direct Request & Transition to S2` — `REQ-SEC-001`, `AC-S03-05`, `Q-01`):**
   - ผู้ขายสามารถกดปุ่ม **"เลือกซาเล้งท่านนี้"** เพื่อส่งคำขอนัดหมายพร้อมรายการของเก่าในฉบับร่างไปยังซาเล้งคนดังกล่าวโดยตรง
   - ระบบตั้งเวลานับถอยหลังรอการตอบรับ 15 นาที โดยคำขอจะเปลี่ยนสถานะเป็น **`S2 (Matched / Pending)`** พร้อมบันทึกประวัติลงใน `AuditLog`
   - หากซาเล้งไม่ตอบรับภายใน 15 นาที หรือกดปฏิเสธ ระบบจะแจ้งเตือนผู้ขายเพื่อเลือกซาเล้งท่านใหม่ หรือเปลี่ยนเป็นประกาศงานทั่วไป (`Open Broadcast`)

> [!NOTE]
> **ขอบเขตและสิ่งที่จงใจไม่ทำ (Non-goals — `Q-05`):**
> 1. **ไม่ทำระบบโทรผ่านอินเทอร์เน็ต (In-App VoIP):** ใช้ Native Phone Dialer (`tel:`) ของอุปกรณ์ หรือการแชตข้อความในแอป เพื่อประหยัดทรัพยากรตาม `CC-01`
> 2. **ไม่ทำระบบต่อรองราคาค่าเดินทางนอกรอบ:** ยึดตามเกณฑ์การคำนวณราคากลางและเงื่อนไขระยะทางที่ระบบกำหนด
> 3. **ไม่แสดงซาเล้งที่ปิดรับงานหรือยังไม่ผ่าน KYC:** ซาเล้งที่ปิดสถานะ (`Offline`) หรือสถานะการยืนยันตัวตนยังไม่สมบูรณ์ (`verified != true`) จะไม่ปรากฏในผลการค้นหา

## 2. เกณฑ์การยอมรับ (`Acceptance Criteria`)

- **`AC-S03-01` (Saleng Profile & KYC Verification Display — `REQ-QA-001`, `REQ-SEC-001`):**
  - ผู้ขายต้องเห็นรูปถ่าย ชื่อ สถานะการยืนยันตัวตน (`ยืนยันตัวตนแล้ว 100%`), คะแนนรีวิวเฉลี่ย, สถิติจำนวนงานที่สำเร็จ, และประเภทยานพาหนะของซาเล้งอย่างชัดเจนก่อนกดยืนยันนัดหมาย
- **`AC-S03-02` (Top Pinning for Previous Collectors — `REQ-UX-001`):**
  - หากผู้ขายเคยบันทึกซาเล้งที่เคยใช้บริการไว้ในรายการโปรด ระบบต้องตรึงรายชื่อซาเล้งกลุ่มดังกล่าวไว้บนสุดของผลการค้นหาเสมอ พร้อมป้ายกำกับ `"ซาเล้งที่เคยใช้บริการ"`
- **`AC-S03-03` (Multi-Criteria Filter & Bulky Vehicle Match — `REQ-FN-001`, `CC-03`, `Card 03`):**
  - ผู้ขายสามารถกรองรายชื่อซาเล้งตามระยะทาง (รัศมี `<= 5 กม.`), ประเภทยานพาหนะ, ชนิดของที่รับ, และคะแนนรีวิวได้ โดยหากในคำขอมีของชิ้นใหญ่ ระบบจะแจ้งเตือนและฟิลเตอร์เฉพาะยานพาหนะที่รองรับได้
- **`AC-S03-04` (Direct Contact with PDPA Masking — `REQ-SEC-002`, `CC-06`):**
  - มีปุ่มโทรด่วนและปุ่มแชตสอบถามข้อมูลกับซาเล้งได้โดยตรง โดยระบบต้องไม่เปิดเผยบ้านเลขที่จริงและพิกัดละเอียดของผู้ขายให้ซาเล้งเห็น
- **`AC-S03-05` (Direct Appointment Request & Audit Logging — `REQ-SEC-001`, `MD-STM-04`):**
  - เมื่อผู้ขายกดเลือกซาเล้ง ระบบต้องส่งคำขอนัดหมายเจาะจงบุคคล เปลี่ยนสถานะคำขอเป็น `S2 (Matched / Pending)` พร้อมตัวนับเวลารอตอบรับ 15 นาที และบันทึกประวัติลงใน `AuditLog` ครบถ้วน

## 3. มติคำถามเปิดและการตัดสินใจ (`Open Questions: Q-01 ถึง Q-05`)

| รหัส | ประเด็นที่พิจารณา | มติที่เห็นชอบ (Option A) | เหตุผลและความสอดคล้อง |
| :---: | :--- | :--- | :--- |
| **`Q-01`** | **รูปแบบการส่งคำขอนัดหมาย** | **ส่งแบบ Direct Request เจาะจงซาเล้งที่เลือกก่อน (นับถอยหลัง 15 นาที):** หากซาเล้งปฏิเสธหรือไม่ตอบรับ ระบบจะแจ้งเตือนให้ผู้ขายเลือกคนใหม่ หรือสลับเป็น Open Broadcast (`S2`) | เพิ่มโอกาสให้ผู้ขายได้ซาเล้งที่ไว้วางใจ และควบคุมคิวงานได้ชัดเจน |
| **`Q-02`** | **การจัดลำดับผลการค้นหาซาเล้ง** | **ตรึง "ซาเล้งที่เคยใช้บริการ" ไว้บนสุด (`REQ-UX-001`)** จากนั้นเรียงตามระยะทางใกล้ที่สุด (`Distance ASC`) และคะแนนรีวิว (`Rating DESC`) | ผู้ขายเข้าถึงผู้ให้บริการที่คุ้นเคยได้เร็วที่สุด และลดเวลาเดินทางของซาเล้ง |
| **`Q-03`** | **การกรองประเภทยานพาหนะเมื่อมีของชิ้นใหญ่** | **ระบบตรวจจับของชิ้นใหญ่อัตโนมัติ และแนะนำ/กรองเฉพาะรถกระบะ:** แจ้งเตือนผู้ขายหากซาเล้งที่เลือกไม่มียานพาหนะที่เหมาะสมตาม `Card 03` | ป้องกันปัญหาซาเล้งไปถึงหน้างานแล้วบรรทุกของไม่ได้ |
| **`Q-04`** | **การคุ้มครองข้อมูลส่วนบุคคล (PDPA)** | **แสดงเบอร์โทรซาเล้งให้ผู้ขาย แต่ซ่อนบ้านเลขที่และพิกัดละเอียดของผู้ขาย (`REQ-SEC-002`, `CC-06`):** จนกว่าซาเล้งจะกดยืนยันรับงาน | ปฏิบัติตามกฎหมาย PDPA และป้องกันการละเมิดความเป็นส่วนตัวของผู้ขาย |
| **`Q-05`** | **ขอบเขตสิ่งที่ไม่ทำ (Non-goals)** | **ไม่ทำระบบ In-App VoIP, ไม่ทำระบบประมูลราคาค่าเดินทาง, และไม่แสดงซาเล้ง Offline / Unverified** | รักษาความเรียบง่าย ประหยัดทรัพยากรบนมือถือราคาประหยัดตาม `CC-01` |
